# 使用说明

首次配置见[部署文档](deployment.md)。网页和桌面端连接同一个搜索服务；网页登录密码与 系统的 SMB 登录是两套独立凭据。

## 搜索和筛选

不输入关键词即可浏览全部可见结果。默认只匹配最后一级名称；开启“匹配路径”后也匹配共享内的父目录。

普通词按子串搜索，多个关键词需要同时满足，引号可保留含空格的短语。`*`、`?`、`[]` 使用通配符匹配，不提供正则搜索。类型、精确扩展名和目录范围可以叠加，扩展名不区分大小写。

例如搜索“旅行”：`其他/旅行日记.mkv` 在名称模式下可以命中；`旅行/片段.mp4` 需要开启路径匹配。“目录范围”独立于路径匹配开关，填写相对目录即可限制搜索区域；既可填写 `media/Shows/Friends`，也可直接粘贴 Windows 样式的 `media\Shows\Friends`。

分类按扩展名判断，不读取文件内容。部分格式存在歧义，可用精确扩展名筛选。大小和日期未纳入文件名索引，因此暂不提供按这两个字段对全结果排序。

## 浏览和选择

结果按页传输，窗口仅绘制可见行。显示的总数属于整个查询，不是已加载页数。未加载的区域会短暂显示加载提示。

| 操作 | 行为 |
|---|---|
| Ctrl+F | 聚焦搜索框 |
| 搜索框内 ↓ | 进入结果列表 |
| ↑ / ↓ / Page Up / Page Down / Home / End | 移动选择与浏览位置 |
| Ctrl+单击 | 增减选择 |
| Shift+单击 | 连续选择，可跨页 |
| Ctrl+A | 在搜索框选中文字；在列表选择整个查询结果 |
| Escape | 清除列表选择 |
| F5 | 重新查询当前条件，不重建索引 |

macOS 将上述 Ctrl 快捷键对应为 Command（⌘），例如 ⌘F、⌘A、⌘C、⌘⇧C；⌘+单击可增减选择。

修改搜索条件会清空选择。查询尚在统计时可以先全选，但完整复制、导出要等查询成功完成。查询过期或失败时会明确提示，程序不会把旧选择悄悄套到新结果上。

## 文件访问

Windows 客户端需要填写自己的服务地址、UNC 共享根路径，以及可选的映射盘。仅当盘符指向配置的共享时才使用映射盘，否则回退到 UNC。

macOS 客户端先在 Finder 中按 ⌘K 连接 `smb://nas.example.internal/files`，再在设置中填写同一共享的 UNC 根路径（`\\nas.example.internal\files`）和实际本机挂载路径（例如 `/Volumes/files`）。多个同名共享可能被系统挂载为 `files-1`，应以 Finder 的实际位置为准。搜索服务密码与 SMB 登录独立；搜索密码默认保存到 macOS 钥匙串。

Mac 支持默认应用打开、Finder 定位、显示简介、单个文件复制，以及批量复制和导出 POSIX 路径。⌘Enter 定位文件，Option+Enter 显示简介。挂载离线或与配置的服务器/共享不匹配时，会提示修正连接；不会打开同名本机目录。路径复制与导出只使用索引，不检查每个文件是否存在。

Mac 不内嵌 Windows 系统扩展菜单，也不提供独立的“打开方式”对话框；使用“打开所在位置”后在 Finder 右键操作。Finder 简介可能需要 macOS 自动化授权。

单个文件可双击或按 Enter 用默认应用打开；文件夹在系统文件管理器中打开。以下系统菜单说明针对 Windows。Ctrl+Enter 定位文件，Alt+Enter 显示系统属性，Shift+F10 弹出快捷菜单。桌面打开的是共享原文件，后续保存受应用和 SMB 权限控制。

“系统右键菜单…”支持同目录和跨目录多选，也能解析超过 260 字符的路径；不会跳过长路径文件来凑出部分菜单。长路径选择会向系统扩展提供完整的文件清单，避免 Windows 旧接口导致播放器接收不完整。系统菜单中的“Copy as path”使用客户端的完整路径复制，保留引号、顺序和现有剪贴板容量限制。其他命令仍由 Windows 与对应应用执行，应用自身的去重、播放格式和长路径支持仍会影响处理结果。

系统菜单需要经 Samba 准备真实文件对象，并加载已安装应用的菜单扩展；文件多、所在目录分散时仍可能等待数秒到十几秒。这不同于只查询索引的搜索和全选。客户端会在一次菜单准备过程中复用父目录对象，避免反复访问同一路径；复制或导出路径可直接使用快捷菜单中的对应功能。

网页支持文本、常见图片、PDF 和浏览器兼容音视频的预览，以及文件下载。其他格式可下载后打开。网页不能直接获得 Windows 客户端的全部系统文件操作能力。

搜索结果来自索引，文件可能已被移动或删除。符号链接、特殊文件名和网络路径的处理也存在平台差异；程序会提示访问失败，不自动下载副本冒充打开原文件。

## 分享连接配置

桌面端连接成功后默认安全保存访问密码，不再提供“记住登录”复选框。Windows 使用当前用户的系统加密保护，macOS 使用钥匙串；需要清除时，在连接设置中点“退出并忘记登录”。

在桌面端的**连接设置 → 分享连接配置**中打开二维码，再在 Android 的首次连接页点**扫码导入**。已经连接的 Android 可在设置的连接区域使用“扫码导入连接配置”。手机支持相机识别和“从图片导入”，图片识别不要求相机权限，不依赖 Google 服务。首次使用相机需在扫码页启用并授权。

手机识别后展示服务地址，访问密码不显示在确认界面；点“连接并保存”后才登录。取消或登录失败会保留原连接，成功后替换连接并加密保存手机自己的登录会话。二维码不包含 Windows 共享路径、Mac 挂载路径或桌面登录会话。

分享只使用已保存的地址和密码。修改了桌面表单中的地址或密码但尚未保存时，分享入口禁用；旧版本中没有保存密码的连接也禁用分享，不弹出补输密码的窗口，下一次正常连接成功后自动保存并恢复分享能力。

二维码包含访问密码，不应公开分享。关闭弹窗会清除当前显示，但已经保存或拍摄的二维码不会因此失效；它的登录能力取决于地址、访问密码和服务访问限制。手机仍需能访问 NAS；`localhost`、回环地址和未指定地址不可分享，需要先使用手机可访问的 NAS 地址正常连接。

## Android 客户端

Android 8.0 及以上可安装客户端。正式 APK 与 `.debug` 调试包可并存，两者首次连接分别导入；正式版更新保留同包名的本地配置。构建和安装见[开发文档](development.md#android-构建与安装)。首次填写 NAS Find 服务根地址（`http://` 或 `https://`）、访问密码和可选显示名，无需 SMB 共享、映射盘或挂载路径。服务须允许手机所在网络；客户端不会自动修改 NAS 网络限制。

应用只保留经 Android Keystore 加密的登录会话，不保存访问密码；退出登录会清除会话。主页面顶部统一显示连接与索引状态。有旧索引时，更新或更新失败仍可搜索；登录过期需重新登录。这里没有离线索引，断网时已显示的结果只作为上次结果保留。

### 查找与浏览

- 首页显示本机最近搜索，最多保存 10 条，按服务地址分开；可删除单条、清空或在设置中关闭记录。历史行立即搜索，右侧箭头回填供编辑。
- 输入停顿约 300 ms 后搜索，中文输入法正在组合文字时不查询；键盘“搜索”立即提交。空关键词可以搜索全部结果；首页“浏览文件夹”进入根目录的直接子项列表。最近搜索在提交或使用结果时记录，不记录输入过程中的每个前缀。
- 结果区可快速切换类型；筛选面板可点选目录范围、指定单个扩展名和开启路径匹配；“输入路径”也支持手填相对目录。面板内修改需点“应用筛选”，关闭面板不应用草稿。非默认条件显示在结果上方，点击可移除。
- 点文件夹进入直接子项列表，可返回上一级；“搜索此处”或输入关键词会搜索该目录及子目录。返回恢复之前的查询和位置。逐级浏览与点选搜索范围需要支持 `directory-browse` 的服务端；旧服务端显示明确提示并保留递归搜索。下拉刷新只重新查询，不重建索引；手动校验索引在设置中。
- 点文件按类型打开，长按或点“选择”进入多选。全选包含未加载结果；统计完成前不能复制或导出。多选时条件显示为只读摘要，退出选择后可修改。

### 预览、保存与外部打开

客户端在点开文件后才读取原文件。列表不读取缩略图、大小或修改日期；这些信息按需显示在文件操作菜单与详情中。

| 文件类型 | 默认操作 |
|---|---|
| 图片 | 内置查看，可双击或双指缩放；上一张、下一张在当前结果中查找图片 |
| TXT、日志、代码等纯文本 | 内置只读查看，可选择复制；最多显示前 64 KiB，可打开完整文件 |
| PDF、Office 文档、电子书、CSV | 准备临时副本后用系统默认应用打开 |
| 音视频 | 用系统默认播放器按需读取，支持播放器拖动进度，无需先完整下载 |
| 压缩包 | 用对应应用打开 |
| 程序、未知格式 | 显示文件操作菜单，不自动安装或运行 |

没有默认应用时由 Android 显示选择界面；“打开方式”主动重新选择应用。没有适用应用时可保存文件。图片最多读取 64 MiB，解码长边不超过 2560 像素；具体格式支持依设备而异，动图当前显示静态画面。超限或无法显示时可保存或用其他应用打开。

音视频通过只读 `content://` 文件授权交给播放器；客户端保管登录会话并分段读取 NAS，接收应用不会获得 NAS 密码、会话或 HTTP 地址。每个打开的文件描述符最多缓存 2 MiB 数据，单个读取请求最多等待 15 秒。退出登录会撤销入口；应用进程被结束后需重新从搜索结果打开。兼容性由播放器是否支持 Android 可寻址文件描述符及媒体编码共同决定；不能播放时可换播放器，或明确选择保存完整文件后打开。

“保存到手机”先打开系统位置选择器，确定位置后才开始传输原文件；取消选址不会下载文件内容。传输时显示文件名、已读取字节与总量，可取消并继续搜索。写入失败或取消时会尝试删除未完成的目标文档；第三方文档提供者若不支持删除，需到所选位置清理残留。保存不申请整个存储空间访问权限。

文档的外部打开与“分享文件”使用完整临时副本，仅授予读取权限，修改不写回 NAS。同一服务、路径、大小和版本的副本会复用。临时副本超过 7 天自动清理；总量超过 512 MiB 时优先清理至少 1 小时未重新使用的副本，最近打开的大文件可能使总量暂时超过此值。设置中可手动清理，清理前请关闭外部应用中的相关文件。

同一时间执行一个显式保存、分享准备或导出任务，底部显示进度和取消。任务随应用进程运行，切到后台可以继续，但系统结束进程后不会自动恢复下载；重开后需重新操作。应用不提供常驻下载服务或跨进程断点续传。

### Android 路径清单

复制与导出默认使用 NAS 相对路径。TXT 每行一个路径；CSV 只有“NAS相对路径”一列，每个值以 `./` 开头，并保留引号、换行等特殊字符。这里不生成桌面端的 Windows / Mac 本机路径。

Android 批量剪贴板上限为 256 KiB（按 UTF-16 文本计算），以避免系统跨进程剪贴板传输失败；超过时提示导出，不截断。TXT 或复制遇到换行、反斜杠等歧义名称时提示改用 CSV。导出最多 512 MiB，先在本机准备完整文件再选择保存位置。查询过期、结果不完整或导出取消时不能把部分结果当成完整清单。

## 复制和导出（桌面与网页）

- Ctrl+C 复制文件供资源管理器粘贴，目前仅支持单选。
- Ctrl+Shift+C 复制全部选中的路径，每行一个；右键还提供带引号的路径和 UNC 路径。
- 剪贴板上限按最终 UTF-16 文本计算，为 16 MiB；超过时提示导出，不截断结果。
- TXT 使用 UTF-8、CRLF 换行。名称包含换行或反斜杠时，可使用 CSV 完整清单保留原始 NAS 名称。
- CSV 包含 Windows 样式路径与以 `./` 开头的 NAS 相对路径，按 CSV 规则保留引号和换行。Windows 样式路径不保证适用于所有 Linux 特殊名称。

macOS 默认路径清单使用 POSIX 路径，CSV 第一列为 macOS 路径；“复制 UNC 路径”可生成 Windows 共享路径。TXT 名称含换行时应使用 CSV。

桌面导出保存在系统下载目录的 `NAS Find` 文件夹，完成后可打开所在位置。导出先写临时文件，成功后才发布为新文件；取消或准备失败不会留下半份目标清单。取消可能需要等当前网络请求返回。

网页端在 NAS 上准备完整清单，再交给浏览器下载。最终保存位置由浏览器决定；HTTP 网页的剪贴板操作也可能受浏览器限制。

## 索引状态

没有文件名变化时不执行常规更新。创建、删除或重命名会合并成待更新事件；正文修改本身不触发文件名索引更新。

首次建索引、服务重启后的恢复校验、通知溢出恢复和周期兜底校验仍会读取目录。“更新索引”按钮用于手动安排校验，不等同于 F5 重新搜索。

可见结果数可能略少于索引原始条目数，因为配置排除的目录自身等条目也会被过滤。
