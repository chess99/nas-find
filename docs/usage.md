# 使用说明

首次配置见[部署文档](deployment.md)。网页和桌面端连接同一个搜索服务；网页登录密码与 Windows 的 SMB 登录是两套独立凭据。

## 搜索和筛选

不输入关键词即可浏览全部可见结果。默认只匹配最后一级名称；开启“匹配路径”后也匹配共享内的父目录。

普通词按子串搜索，多个关键词需要同时满足，引号可保留含空格的短语。`*`、`?`、`[]` 使用通配符匹配，不提供正则搜索。类型、精确扩展名和目录范围可以叠加，扩展名不区分大小写。

例如搜索“旅行”：`其他/旅行日记.mkv` 在名称模式下可以命中；`旅行/片段.mp4` 需要开启路径匹配。“目录范围”独立于路径匹配开关，填写相对目录即可限制搜索区域。

分类按扩展名判断，不读取文件内容。部分格式存在歧义，可用精确扩展名筛选。大小和日期未纳入文件名索引，因此暂不提供按这两个字段对全结果排序。

## 浏览和选择

结果按页传输，窗口仅绘制可见行。显示的总数属于整个查询，不是已加载页数。未加载的区域会短暂显示加载提示。

| 操作 | 行为 |
|---|---|
| Ctrl+F | 聚焦搜索框 |
| 搜索框内 ↓ | 进入结果列表 |
| ↑ / ↓ / Page Up / Page Down / Home / End | 移动选择与浏览位置 |
| Ctrl+单击 | 增减选择 |
| Shift+单击 | 连续选择，可跨页 |
| Ctrl+A | 在搜索框选中文字；在列表选择整个查询结果 |
| Escape | 清除列表选择 |
| F5 | 重新查询当前条件，不重建索引 |

修改搜索条件会清空选择。查询尚在统计时可以先全选，但完整复制、导出要等查询成功完成。查询过期或失败时会明确提示，程序不会把旧选择悄悄套到新结果上。

## 文件访问

Windows 客户端需要填写自己的服务地址、UNC 共享根路径，以及可选的映射盘。仅当盘符指向配置的共享时才使用映射盘，否则回退到 UNC。

单个文件可双击或按 Enter 用默认应用打开；文件夹在资源管理器中打开。Ctrl+Enter 定位文件，Alt+Enter 显示系统属性，Shift+F10 弹出快捷菜单。桌面打开的是共享原文件，后续保存受应用和 SMB 权限控制。

“系统右键菜单…”支持同目录和跨目录多选，也能解析超过 260 字符的路径；不会跳过长路径文件来凑出部分菜单。长路径选择会向系统扩展提供完整的文件清单，避免 Windows 旧接口导致播放器接收不完整。系统菜单中的“Copy as path”使用客户端的完整路径复制，保留引号、顺序和现有剪贴板容量限制。其他命令仍由 Windows 与对应应用执行，应用自身的去重、播放格式和长路径支持仍会影响处理结果。

系统菜单需要经 Samba 准备真实文件对象，并加载已安装应用的菜单扩展；文件多、所在目录分散时仍可能等待数秒到十几秒。这不同于只查询索引的搜索和全选。客户端会在一次菜单准备过程中复用父目录对象，避免反复访问同一路径；复制或导出路径可直接使用快捷菜单中的对应功能。

网页支持文本、常见图片、PDF 和浏览器兼容音视频的预览，以及文件下载。其他格式可下载后打开。网页不能直接获得 Windows 客户端的全部系统文件操作能力。

搜索结果来自索引，文件可能已被移动或删除。符号链接、特殊文件名和网络路径的处理也存在平台差异；程序会提示访问失败，不自动下载副本冒充打开原文件。

## 复制和导出

- Ctrl+C 复制文件供资源管理器粘贴，目前仅支持单选。
- Ctrl+Shift+C 复制全部选中的路径，每行一个；右键还提供带引号的路径和 UNC 路径。
- 剪贴板上限按最终 UTF-16 文本计算，为 16 MiB；超过时提示导出，不截断结果。
- TXT 使用 UTF-8、CRLF 换行。名称包含换行或反斜杠时，可使用 CSV 完整清单保留原始 NAS 名称。
- CSV 包含 Windows 样式路径与以 `./` 开头的 NAS 相对路径，按 CSV 规则保留引号和换行。Windows 样式路径不保证适用于所有 Linux 特殊名称。

桌面导出保存在系统下载目录的 `NAS Find` 文件夹，完成后可打开所在位置。导出先写临时文件，成功后才发布为新文件；取消或准备失败不会留下半份目标清单。取消可能需要等当前网络请求返回。

网页端在 NAS 上准备完整清单，再交给浏览器下载。最终保存位置由浏览器决定；HTTP 网页的剪贴板操作也可能受浏览器限制。

## 索引状态

没有文件名变化时不执行常规更新。创建、删除或重命名会合并成待更新事件；正文修改本身不触发文件名索引更新。

首次建索引、服务重启后的恢复校验、通知溢出恢复和周期兜底校验仍会读取目录。“更新索引”按钮用于手动安排校验，不等同于 F5 重新搜索。

可见结果数可能略少于索引原始条目数，因为配置排除的目录自身等条目也会被过滤。
