# 全结果浏览、分类与批量路径操作

> 历史归档：保留当时的方案与验证结论，环境标识已匿名化，不对应实际部署目标。当前行为见[使用说明](../usage.md)，部署步骤见[部署文档](../deployment.md)，文档规范见[文档目录](../README.md)。

本轮开始时间：2026-09-06 23:15。版本：0.2.0。此文替代第一版使用说明中关于 200 条显示上限、仅单选和扩展名下拉框的描述。

## 当前操作

- 名称匹配为默认行为；勾选“匹配路径”后，也匹配父目录。匹配范围是共享内可见的相对路径，不包含内部 `/srv/storage` 前缀。
- 类型支持全部、视频、音频、图片、文档、压缩包、程序和文件夹。扩展名可独立输入，与类型、目录范围同时生效。
- 分类使用大小写无关的扩展名集合，目录使用索引发布时的目录集合识别，不访问文件内容；`.ts` 等歧义扩展名未默认归入视频。
- 不输入关键词即可浏览全部可见条目；结果不再以 200 或 10,001 条截断。
- 每次加载最多 500 条，客户端缓存最多 12 页，只绘制当前可见区域及少量缓冲行。滚动到未加载区域时短暂显示加载提示。
- Ctrl+A 在搜索框中选择文字，在结果列表中选择整个查询结果，包括没有加载的页。Ctrl 单击增减选择，Shift 单击选择连续范围，Escape 清除选择。
- 查询尚未完成时可以先全选，状态栏显示正在统计；完整复制、导出仅在查询成功完成后启用。
- 新搜索或筛选会清空选择。已经开始的路径操作继续使用开始时的选择和查询快照。

## 多选菜单与复制

多选菜单只包含路径操作和取消选择，不加载 Windows Shell 扩展，也不逐个读取文件属性。单选仍支持默认应用打开、定位、打开方式、复制文件、系统属性。

Ctrl+C 仍表示复制文件，仅支持单选；不会在多选时偷偷改成复制文本。Ctrl+Shift+C 复制完整路径，每行一个。右键还可复制带引号的路径、UNC 路径，或导出清单。

剪贴板按最终 UTF-16 文本大小限制为 16 MiB，而不是限制项目数量。超过阈值会提示导出；不会截断成前几千条。准备阶段的取消、网络失败、查询过期不会写入半份剪贴板内容。

客户端的常用导出直接保存到系统下载目录下的 `NAS Find` 文件夹，以日期时间生成唯一文件名。完成后提供“打开所在位置”。选择这个默认行为，是因为本机系统保存对话框首次初始化曾明显延迟，影响导出体验。

TXT 为 UTF-8、一行一个路径，CRLF 换行。CSV 完整清单包含“Windows样式路径”和“NAS相对路径”两列，UTF-8 BOM，按 CSV 标准处理引号与换行。名称含换行或反斜杠时，TXT 无法无歧义表达，程序提示改用 CSV，绝不跳过这些项目。CSV 的 NAS 相对路径以 `./` 开头，保留原始名称；少数 Linux 特殊名称可能无法直接用 Windows 样式路径打开。

导出先写同目录临时文件，完成后发布为新文件；取消或失败清理临时文件，不覆盖已有文件。批量操作可取消，网络故障时可能需要等待当前请求超时。完成前不报告成功。

网页端共用相同筛选、虚拟列表与选择逻辑；路径使用服务端配置的 UNC。网页 TXT/CSV 在 NAS SSD 上准备完整文件后交给浏览器下载；浏览器最终保存位置和下载取消由浏览器管理。普通 HTTP 页面剪贴板受浏览器限制，失败时可使用导出或 Windows 客户端。

## 服务端设计

每次查询形成一份不可变快照：读取 plocate 索引，在系统 SSD 上写入带序号的临时 SQLite 结果表。名称模式使用 plocate `--basename`；路径模式在可见相对路径上匹配。分类、目录和扩展名筛选在分页之前完成。没有正文扫描，也没有逐文件存在性检查。

查询启动时在发布锁内固定数据库版本与目录集合，索引更新后旧结果的序号仍稳定。分页按序号直接定位，不重复搜索并丢弃前 N 条。全选采用“全部 + 排除区间”，普通多选采用区间集合；四百万条全选也只需一个标记。

批量路径接口验证会话所属关系、查询是否完整以及选择范围。返回完整选中数量、后续读取位置和完成标志。过期时明确失败，不自动换成一份新查询。

为控制资源，查询工作线程为 2 个，默认 15 分钟未访问过期，最多保留 24 个查询快照；磁盘总量达到约 2 GiB 时回收旧的已完成快照。单查询快照超过 512 MiB 或超过 120 秒会明确失败，部分结果不可导出。网页待下载清单最多保留 4 份，每份不超过 512 MiB。当前桌面清单直接分批写到 Windows 本机，不受网页下载文件额度限制。

查询缓存和导出缓存均在 `~/.local/state/nas-find/queries/`，可随服务退出或缓存过期清理。当前可见结果数可能略少于索引原始条目数，因为界面还排除了配置中不应显示的目录自身等条目。

## 接口

| 接口 | 用途 |
|---|---|
| POST `/api/query` | 创建查询，返回快照 id |
| GET `/api/query?id=…&offset=…&limit=500` | 获取进度、总数和指定页 |
| POST `/api/query/cancel` | 取消未完成查询 |
| POST `/api/query/selection` | 分批读取选择对应的路径 |
| POST `/api/query/export` | 网页端准备完整 TXT / CSV |
| GET `/api/query/download?token=…` | 下载当前会话准备的清单 |

旧 `/api/search` 保留原接口供旧客户端兼容；新版网页和桌面端使用新的快照接口，不受旧上限影响。

## 验证

- 真实 plocate 测试数据包含 10,050 个先出现的文本结果和 620 个后出现的视频结果，验证视频不会被候选上限漏掉。
- 验证类型、空关键词浏览、大小写、名称与路径差异、独立目录限制、跨页排除区间、完整导出、会话隔离、查询过期、失败时禁止导出、索引发布后旧快照稳定。
- CSV 测试包含换行和反斜杠名称，读取后逐项恢复原始名称。
- 前端验证四百万条全选为固定大小状态、跨页 Shift 选择、Ctrl 取消选择和新查询清空状态。
- 实机接口样本：339,601 个可见结果约 1.2 秒完成，视频 53,707 个约 0.9 秒；视频全选排除 7 项，完整读回 53,700 项。数据仅为当时环境下的样本。
- 原生窗口验证：空关键词显示完整总数，Ctrl+A 选择全部 339,601 项，多选菜单直接弹出；超过 16 MiB 时正确提示导出且未改变剪贴板。
- 最终验证：NAS 的 11 项测试、前端 6 项测试、Rust 6 项本地测试通过。Rust 另一个旧版真实连接测试默认忽略；本轮使用新接口实测补充。
- 取消验证：在第一批 HTTP 响应返回前注入取消，确认已开始写入的临时导出被清理，目标文件没有出现。
- 客户端实测完整复制 53,707 条视频路径，剪贴板为 9,300,904 字节 UTF-16；本机 TXT 导出有同样 53,707 条，按 UTF-16 重新编码后的 SHA-256 与剪贴板完全一致。
- 本机 CSV 导出完成 339,601 条记录，文件 69,120,102 字节。网页接口 CSV 完整读回 339,601 条，包含 1 条特殊名称，逐项比对原始相对路径没有遗漏；UNC 列较长，网页清单为 74,231,113 字节。
- End 键可直接跳到全部结果的末页，先显示加载提示，再按需显示末页内容；没有把所有结果元素插入界面。
- 最终客户端安装在 `%LOCALAPPDATA%\NAS Find`，版本 0.2.0；网页和 NAS 服务已同步更新。验证生成的本机清单保存在系统下载目录的 `NAS Find` 文件夹中。

源码中 `nasfind/static/explorer.js`、`selection.js` 和 `explorer.css` 为两端共用实现。桌面构建前通过 `desktop/sync.mjs` 同步到打包目录；生成副本不进入 Git。构建和安装仍使用 `desktop/build.ps1` 与 `install.ps1`。
