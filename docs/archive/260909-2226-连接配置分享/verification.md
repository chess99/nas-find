# 连接配置分享与默认保存登录

本文件为 2026-09-09 的阶段验证记录。当前行为见[使用说明](../../usage.md#分享连接配置)，构建与互通约定见[开发文档](../../development.md#连接二维码互通)。

## 本轮取舍

- 删除桌面“记住登录”复选框，连接成功后默认使用系统安全机制保存密码；保留“退出并忘记登录”。旧配置没有密码时禁用分享，不增加补输窗口。
- 分享入口放在连接设置的 NAS 地址/密码区域，与电脑专用的 SMB 设置分组。未保存的地址或密码不能分享；二维码单独显示，关闭后清空画布并返回设置。
- Android 首次连接页提供“扫码导入”，设置页的连接区域保留入口；支持相机和选图，识别后确认服务地址，成功登录后才替换连接。
- 二维码传递地址与密码，不复制桌面会话，不增加 NAS 配对服务、令牌管理或数据库。NAS 服务无需更新。

桌面测试生成器产生的合成 GIF/JSON 只进入 Android 测试 APK。实际地址、密码、二维码、原始设备日志和安装包留在被忽略的本地目录。

Windows 安装后的 EXE 与构建目录的 EXE 仅有 Tauri 包类型标记不同（安装包内为 `NSS`，构建目录恢复为 `UNK`），其余字节一致；不以未经处理的两个 SHA256 不同误判更新失败。真机安装曾等待用户确认，用户回来后重新安装成功。相机与扫码互通的自动化验证在模拟器完成，未将真机安装启动算作实拍扫码验收。

## 包体比较

Android 使用改动前提交与本轮源码、同一 JDK/SDK/Gradle 配置分别干净构建；未开启代码压缩。Windows 比较同版本本地 NSIS 构建。以下为文件字节数，不与正式裁剪发行包混为一谈。

| 产物 | 改动前 | 改动后 | 增量 |
|---|---:|---:|---:|
| Windows 安装包 | 2,945,579 | 2,964,570 | 18,991，约 19 KB / 0.64% |
| Android 调试 APK（干净构建） | 16,329,184 | 16,732,472 | 403,288，约 0.40 MB / 2.47% |

曾测得多轮增量打包后的 Android APK 接近 20 MB；ZIP 实际条目只增长约 0.40 MB，额外空间来自打包产物的空洞。干净构建后消除，未通过删除必要依赖或改变优化设置来制造更小增量。

本轮为本地功能构建，没有发布 Release 或推送标签。安装包版本沿用当前工程版本，精确内容由提交与本地校验和识别。
