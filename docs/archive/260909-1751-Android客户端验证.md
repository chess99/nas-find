# Android 客户端首版验证记录

历史记录，建立于 2026-09-09。当前操作与构建要求以[使用说明](../usage.md#android-客户端)、[开发文档](../development.md#android-构建与安装)为准。

## 实现范围

在独立 `android/` 工程中实现 Kotlin / Compose 客户端，复用现有服务接口，没有修改服务端或现有桌面客户端。首版版本为 `0.1.0-debug`，最低 API 26，编译/目标 API 34。

实现登录与加密会话、单页搜索入口、最近搜索、筛选草稿、按需分页、递归目录范围、跨页全选、相对路径复制与 TXT/CSV 导出、文本/图片/PDF 预览、系统媒体播放器、系统位置选择器保存、FileProvider 外部打开。主页面没有底部导航与大 Logo，状态集中在顶部；底部仅按当前多选、传输或 PDF 翻页需求展示操作。

## 具体边界

- 实际设备验证为 Android 14 模拟器；API 26–33 真机、所有厂商系统、多种视频编码、深色主题和横屏尚未完成全面验证。音视频不能解码时可保存或外部打开。
- 传输依赖应用进程，没有前台下载服务或跨进程断点续传。进程结束后重新操作；旧的未完成临时文件在下次启动清理。
- Android 剪贴板上限为 256 KiB，导出上限为 512 MiB；图片预览加载上限 64 MiB、解码长边 2560 像素，PDF 加载上限 128 MiB。超限可改为保存完整文件或外部打开。
- 系统保存失败时尝试删除未完成文档；第三方文档提供者不支持删除时需手动清理残留。外部打开只有读取授权，不提供 NAS 原文件编辑与写回。
- 当前交付为调试签名 APK，正式签名、商店上架和 Android Release 自动发布不在本轮交付内。
